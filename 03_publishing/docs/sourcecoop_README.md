## Overview / 概要

Map tiles (Web Mercator, z8–18; XYZ and PMTiles) of a 0.5 m DEM, hillshade and CS map for Tottori Prefecture, Japan.
The DEM was **independently generated from airborne LiDAR point clouds provided by Tottori Prefecture**, which resolves some errors found in the published DEM.
Intended for web mapping, teaching (XYZ tile exercises), and terrain analysis.

鳥取県全域の 0.5 m DEM・陰影図・CS立体図のタイル（Web メルカトル、z8–18、XYZ および PMTiles）です。
DEM は**鳥取県から提供を受けた航空レーザ測量の点群から独自に作成**したもので、公開版 DEM に見られる一部のエラーを解消しています。
Web 地図での利用、XYZ タイルを読み込む実習、地形判読を想定しています。

- Tiling scheme: WebMercatorQuad (EPSG:3857), XYZ convention (y from top), 256 px
- Zoom: 8–18 (z18 ≈ 0.49 m/px at 35.4°N, matching the 0.5 m source grid)

## Elevation PNG encoding / 標高PNGの形式

Same encoding as the GSI (Geospatial Information Authority of Japan) elevation PNG tiles, 0.01 m resolution.
国土地理院「標高タイル（PNG形式）」と同じ形式（分解能 0.01 m）。

```
x = R * 2^16 + G * 2^8 + B
if x <  2^23: h = x * 0.01          (m)
if x >  2^23: h = (x - 2^24) * 0.01 (m)
(R,G,B) = (128,0,0): NoData
```

Note: This is **not** Mapbox Terrain-RGB / Terrarium. MapLibre GL JS needs a custom protocol to use it as `raster-dem`.
注意: Terrain-RGB / Terrarium 形式ではありません。MapLibre で `raster-dem` として使う場合は変換用のカスタムプロトコルが必要です。

## Processing / 作成方法

**Source DEM / 元DEM**
- LiDAR point clouds (LAZ) provided by Tottori Prefecture on request (not publicly downloadable)
- 0.5 m DEM generated by TIN interpolation (max TIN edge 50 m), JGD2011 / Japan Plane Rectangular CS V (EPSG:6673), float32, NoData -9999
- 鳥取県に請求して提供を受けた航空レーザ測量点群（LAZ、非公開）から、TIN 補間（最大辺長 50 m）で 0.5 m DEM を作成

**Elevation PNG / 標高PNG** (`scripts/gsi_dem_tiles.py`, GDAL 3.13)
- z18: source DEM reprojected per tile to EPSG:3857 with bilinear resampling (float), then encoded
- z17–z8: 2×2 mean of the four decoded child tiles (NoData excluded), re-encoded
- Validation: random 150 z18 tiles / 17,260 points vs. independent bilinear sampling of the source DEM: max |diff| = 0.005 m (rounding only)

**Hillshade / 陰影図**
- Source: 0.5 m hillshade computed from the DEM
- `gdal raster tile -r bilinear --overview-resampling=average --add-alpha` (z18 from full resolution; lower zooms downsampled from tiles)

**CS Map / CS立体図**
- Source: 0.5 m CS map computed from the DEM. Slope σ = 0.75 m, curvature σ = 2.25 m (negative Laplacian), coefficient 1.1
  composition `(0.125H + 0.125C1 + 0.25S1 + 0.5C2) * S2/255`
- `gdal raster tile -r bilinear --overview-resampling=average` (same as hillshade)

## Notes / 注意事項

- Survey years differ by area (FY2018–FY2024). See Tottori Prefecture's data list (https://www.pref.tottori.lg.jp/secure/1386525/datelist_R80107_compressed.pdf).
- 計測年度は区域により異なる（平成30〜令和6年度）。
- Datum: JGD2011 is treated as identical to WGS84 for Web Mercator reprojection (null transformation).
- Tottori Prefecture also publishes its own DEM and CS map tiles on G空間情報センター (https://www.geospatial.jp/ckan/dataset/dem05_tottori , https://www.geospatial.jp/ckan/dataset/csmap_tottori). This product is independently generated from the point clouds and differs from them.
- 鳥取県も G空間情報センターで DEM・CS立体図のタイルを公開しています。本プロダクトは点群から独自に作成したもので、それらとは別物です。
